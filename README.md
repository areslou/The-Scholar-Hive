# The Scholar Hive

A scholar directory and admin dashboard built for the **Lasallian Scholars Society (LSS)** at De La Salle University.

## The problem

When a scholarship opens up or a requirement is due, LSS officers need to reach the right scholars quickly. Keeping track of who is who across spreadsheets and group chats makes that slow, and messages get missed.

## What it does

- **Scholar directory:** one searchable list of members and their details
- **Admin dashboard:** officers manage records in one place
- **Email blasts:** send announcements straight to scholars when scholarships or requirements come up
- **File uploads:** attach and store supporting files

## Built with

PHP, MySQL, HTML/CSS, JavaScript

## Running it locally

1. Install a local PHP + MySQL stack (for example XAMPP).
2. Copy this folder into your server's web root (for XAMPP: `htdocs`).
3. Create the database and import the schema file, if one is included.
4. Update the database connection settings to match your local setup.
5. Open `http://localhost/The-Scholar-Hive` in your browser.

> Note: email sending needs SMTP settings. Do not commit real passwords or API keys to this repo.
